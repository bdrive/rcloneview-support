# RcloneView 1.5 – リリースノート

**リリース日:** 2026年7月<br/>
**対応プラットフォーム:** Windows、macOS、Linux

RcloneView 1.5 では、空の状態から最初のタスク完了までを案内するオンボーディングウィザード、自動バージョンバックアップ、インラインファイルプレビュー、新しい RcloneView Mobile アプリとの連携、暗号化リモートの刷新された画面に加え、全プラットフォームにわたる数多くの安定性・使いやすさの修正が導入されました。

## ハイライト

- **オンボーディングウィザード（新規）:**
  ステップバイステップのウィザードが、空の状態から最初のタスク完了までをすべて案内します。
  バックアップ、同期、コピー、比較、マウント、または暗号化（Crypt）リモートの設定から目的を選ぶと、
  プロバイダーの選択、リモートの構成と認証（OAuth を含む）、接続の確認、コピー元・コピー先フォルダーの選択、
  実際のドライランによる結果のプレビュー、そして実行までをガイドに沿って進められます。
  ウィザードは初回起動時に自動的に開き、ツールバーからいつでも利用できます。さらに、コピー先フォルダーを
  その場で新規作成したり、実行中のドライランプレビューをキャンセルしたり、完了後に結果をファイルエクスプローラーや
  マウント済みフォルダーで開いたりでき、同期・バックアップジョブはそのままジョブマネージャーに保存されます。

- **自動バックアップ:**
  ファイルの以前のバージョンを安全に保つ新しいバックアップ機能を追加しました。バージョンバックアップは上書き・
  削除されたファイルをタイムスタンプ付きのバックアップディレクトリに移動し、最新 N 件を保持する保持ポリシーが
  古いバージョンを自動的に整理します。また、新しいシンプルスケジュールモードにより定期バックアップの設定が
  簡単になりました。スケジューラーの信頼性も向上しています。

- **インラインファイルプレビュー:**
  ファイルエクスプローラーを離れずにファイルをプレビューできます。画像と PDF をインラインで表示し、ブラウザー
  パネル内でサムネイル付きの動画を再生できます。

- **RcloneView Mobile:**
  新しい RcloneView Mobile アプリと RcloneView をペアリングできます。*Send to Mobile* を使うと QR コード経由で
  設定をモバイルアプリに書き出せます。8 言語にローカライズされました。

## 新機能

- **暗号化（Crypt）リモート画面の刷新:**
  暗号化（Crypt）リモートの扱いが大幅に分かりやすくなりました。専用バナー、クロスオープンボタン、ツールチップ、
  インラインヘルプが現在の画面を説明し、ロックされたリスト表示・ツリー表示では復号のヒントと対になるパネルを
  表示します。オフラインでのファイル名のエンコード／デコードにも対応しています。

- **Proton Drive の再サポート:**
  Proton Drive がリモートプロバイダーとして再び利用可能になり、mailbox_password にも対応しました
  （rclone v1.73.5 で検証済み）。Proton Drive は上流の変更により 1.4 で削除されていました。

- **マウント後にファイルマネージャーを自動で開く:**
  リモートのマウント完了時にシステムのファイルマネージャーを自動的に開くよう設定できます。マウントごとに
  設定可能です。

- **パス選択画面での新規フォルダー作成:**
  ウィザード、同期、操作、マウントの各フローのパス選択画面から、コピー先フォルダーを直接新規作成できます。

## バグ修正

- **Dropbox Business のチームフォルダー:**
  チームフォルダーのコピーや同期時に発生する「Directory not found」エラーを修正しました。

- **グローバル rclone フラグが無視される問題:**
  エクスプローラーでフォルダーをコピーする際にグローバルフラグ（例: --transfers）が適用されるようになり、
  マウントキャッシュディレクトリとグローバルフラグがマウントに正しく適用されるようになりました。

- **macOS でアプリが起動しない問題:**
  メインウィンドウが表示されずアプリを開けなくなる不具合に対して、セーフガードを追加しました。

- **macOS のマウントマネージャーのスピナー:**
  マウントマネージャーでスピナーが終わらない問題を修正しました。

- **トレイの「すべてアンマウント」:**
  トレイの「すべてアンマウント」で実際にアンマウントされない問題を修正しました。

- **転送の進捗:**
  新しいジョブの進捗が「転送」タブに表示されない問題を修正し、確認ダイアログを是正しました。

- **Linux でのファイル名変更時のハング:**
  Linux でファイル名を変更した後、ファイル一覧の読み込みが終わらない問題を修正しました。

- **リストの並び順:**
  コピー／移動やフォルダー移動の後も、リスト表示で選択した並び順が保持されるようになりました。

- **ウィンドウが狭いときの見切れ:**
  ジョブダイアログの列見出しの見切れと、ジョブマネージャーダイアログの文字切れを修正し、メインウィンドウの
  最小サイズと既定サイズを調整しました。

- **Crypt の OAuth 更新:**
  暗号化された設定で OAuth トークンが更新された際に「構成が変更されました」と誤って通知される問題を
  修正しました。

- **旧バージョンの rclone とローカライズ:**
  旧バージョンの rclone（&lt;1.66）での Send to Mobile、カスタムダイアログでの韓国語の文字化け、埋め込み
  rclone 設定の「更新」ボタンの見切れを修正しました。
