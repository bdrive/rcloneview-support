# RcloneView 1.5 – 릴리스 노트

**출시일:** 2026년 7월<br/>
**지원 플랫폼:** Windows, macOS, Linux

RcloneView 1.5에서는 빈 설정 상태에서 첫 작업 완료까지 안내하는 온보딩 마법사, 자동 버전 백업, 인라인 파일 미리보기, 새로운 RcloneView Mobile 앱 연동, 새롭게 디자인된 암호화 리모트 화면과 함께 모든 플랫폼에 걸친 다양한 안정성 및 사용성 개선 사항이 도입되었습니다.

## 주요 변경 사항

- **온보딩 마법사 (신규):**
  단계별 마법사가 빈 설정 상태에서 첫 작업 완료까지 전 과정을 안내합니다.
  백업, 동기화, 복사, 비교, 마운트 또는 암호화(Crypt) 리모트 설정 중 목표를 선택하면 제공업체 선택,
  리모트 구성 및 인증(OAuth 포함), 연결 확인, 원본·대상 폴더 선택, 실제 드라이 런으로 결과 미리보기,
  실행까지 안내에 따라 진행할 수 있습니다.
  마법사는 최초 실행 시 자동으로 열리며 툴바에서 언제든 다시 실행할 수 있습니다. 또한 대상 폴더를 즉석에서
  새로 만들고, 진행 중인 드라이 런 미리보기를 취소하고, 완료 후 결과를 파일 탐색기나 마운트된 폴더에서 바로
  열 수 있으며, 동기화·백업 작업은 작업 관리자에 그대로 저장됩니다.

- **자동 백업:**
  파일의 이전 버전을 안전하게 보관하는 새로운 백업 기능이 추가되었습니다. 버전 백업은 덮어쓰이거나 삭제된
  파일을 타임스탬프가 붙은 백업 디렉터리로 옮기고, 최근 N개 보관 정책이 오래된 버전을 자동으로 정리하며,
  새로운 단순(Simple) 예약 모드로 반복 백업을 손쉽게 설정할 수 있습니다. 스케줄러 안정성도 개선되었습니다.

- **인라인 파일 미리보기:**
  파일 탐색기를 벗어나지 않고 파일을 미리 볼 수 있습니다. 이미지와 PDF를 인라인으로 확인하고, 브라우저
  패널에서 썸네일 미리보기와 함께 동영상을 재생할 수 있습니다.

- **RcloneView Mobile:**
  새로운 RcloneView Mobile 앱과 RcloneView를 연결하세요. *Send to Mobile* 기능으로 QR 코드를 통해 설정을
  모바일 앱으로 내보낼 수 있으며, 이제 8개 언어를 지원합니다.

## 신규 기능

- **암호화(Crypt) 리모트 화면 재설계:**
  암호화(Crypt) 리모트를 훨씬 명확하게 다룰 수 있습니다. 전용 배너, 교차 열기 버튼, 툴팁, 인라인 도움말이
  현재 보고 있는 화면을 설명하고, 잠긴 목록·트리 뷰에서는 복호화 힌트와 짝을 이루는 패널을 보여주며,
  오프라인 파일명 인코딩/디코딩도 지원합니다.

- **Proton Drive 재지원:**
  Proton Drive를 리모트 제공업체로 다시 사용할 수 있으며, 이제 mailbox_password를 지원합니다
  (rclone v1.73.5에서 검증). Proton Drive는 업스트림 변경으로 인해 1.4에서 제거되었습니다.

- **마운트 후 파일 관리자 자동 열기:**
  리모트가 마운트되면 시스템 파일 관리자를 자동으로 열도록 설정할 수 있으며, 마운트별로 지정할 수 있습니다.

- **경로 선택기에서 새 폴더 만들기:**
  마법사, 동기화, 작업, 마운트 흐름의 경로 선택기에서 대상 폴더를 바로 새로 만들 수 있습니다.

## 버그 수정

- **Dropbox Business 팀 폴더:**
  팀 폴더를 복사하거나 동기화할 때 발생하던 "Directory not found" 오류를 수정했습니다.

- **전역 rclone 플래그 미적용:**
  탐색기에서 폴더를 복사할 때 전역 플래그(예: --transfers)가 적용되며, 마운트 캐시 디렉터리와 전역 플래그가
  마운트에 올바르게 적용됩니다.

- **macOS 앱 실행 불가:**
  메인 창이 나타나지 않아 앱을 열 수 없던 문제에 대한 안전장치를 추가했습니다.

- **macOS 마운트 관리자 스피너:**
  마운트 관리자에서 스피너가 끝없이 도는 문제를 수정했습니다.

- **트레이 "모두 마운트 해제":**
  트레이의 "모두 마운트 해제" 동작이 실제로 마운트를 해제하지 않던 문제를 수정했습니다.

- **전송 진행률:**
  새 작업의 진행률이 전송 탭에 표시되지 않던 문제를 수정하고 확인 대화상자를 바로잡았습니다.

- **Linux 파일 이름 변경 멈춤:**
  Linux에서 파일 이름을 변경한 뒤 파일 목록 로딩이 끝나지 않던 문제를 수정했습니다.

- **목록 정렬 순서:**
  복사·이동 및 폴더 이동 후에도 목록 보기에서 선택한 정렬 순서가 유지됩니다.

- **좁은 창에서의 잘림:**
  작업 대화상자의 열 제목 잘림과 작업 관리자 대화상자의 텍스트 잘림을 수정하고, 메인 창의 최소 크기와 기본
  크기를 조정했습니다.

- **Crypt OAuth 갱신:**
  암호화된 구성에서 OAuth 토큰이 갱신될 때 "구성이 변경됨" 알림이 잘못 표시되던 문제를 수정했습니다.

- **구버전 rclone 및 현지화:**
  구버전 rclone(&lt;1.66)에서의 Send to Mobile, 사용자 지정 대화상자의 한글 깨짐, 내장 rclone 설정의 업데이트
  버튼 잘림을 수정했습니다.
