# RcloneView 1.5 – Release Notes

**Release Date:** July 2026<br/>
**Platforms:** Windows, macOS, Linux

RcloneView 1.5 introduces a guided Onboarding Wizard that takes you from an empty setup to your first completed task, automatic versioned backups, inline file previews, pairing with the new RcloneView Mobile app, and a redesigned view for encrypted remotes — alongside many stability and usability fixes across all platforms.

## Highlights

- **Onboarding Wizard (New):**
  A step-by-step wizard guides you from an empty setup all the way to your first completed task.
  Choose a goal — Backup, Sync, Copy, Compare, Mount, or set up an Encrypted (Crypt) remote — then follow guided steps
  to pick a provider, configure and authenticate the remote (including OAuth), verify the connection, choose your
  source and destination folders, preview the outcome with a real dry run, and execute.
  The wizard launches automatically on first run and is always available from the toolbar. It also lets you create
  new destination folders on the fly, cancel a running dry-run preview, open the result in the file explorer or
  mounted folder when finished, and saves sync/backup jobs straight to the Job Manager.

- **Automatic Backup:**
  New backup capabilities keep previous versions of your files safe. Versioned backups move overwritten and deleted
  files into a timestamped backup directory, a keep-last-N retention policy automatically prunes older versions, and
  a new Simple scheduling mode makes recurring backups easy to set up. Scheduler reliability has also been improved.

- **Inline File Preview:**
  Preview files without leaving the file explorer. View images and PDFs inline, and play videos with thumbnail
  previews directly in the browser panel.

- **RcloneView Mobile:**
  Pair RcloneView with the new RcloneView Mobile app. Use *Send to Mobile* to export your configuration to the
  mobile app via QR code — now localized in 8 languages.

## New Features

- **Redesigned Crypt Remote View:**
  Working with encrypted (Crypt) remotes is much clearer. A dedicated banner, a cross-open button, tooltips, and
  inline help explain what you are looking at; locked list and tree views show decryption hints and paired panels;
  and offline filename encode/decode is supported.

- **Proton Drive Re-Supported:**
  Proton Drive is available again as a remote provider, now including mailbox_password support (verified against
  rclone v1.73.5). Proton Drive had been removed in 1.4 due to upstream changes.

- **Auto-Open File Manager After Mount:**
  Optionally open your system file manager automatically once a remote is mounted, configurable per mount.

- **Create New Folder in Path Picker:**
  Create a new destination folder directly from the path picker in the Wizard, Sync, Operation, and Mount flows.

## Bug Fixes

- **Dropbox Business Team Folders:**
  Fixed "Directory not found" errors when copying or syncing team folders.

- **Global Rclone Flags Ignored:**
  Global flags (e.g., --transfers) are now applied when copying folders in the explorer, and the mount cache
  directory and global flags are correctly applied to mounts.

- **macOS App Not Launching:**
  Added safeguards for a bug where the main window sometimes never appeared, leaving the app unopenable.

- **macOS Mount Manager Spinner:**
  Fixed an infinite spinner in the Mount Manager.

- **Tray "Unmount All":**
  Fixed the tray "Unmount all" action not actually unmounting.

- **Transfer Progress:**
  Fixed new job progress not showing on the Transfer tab, and corrected the confirmation dialog.

- **Linux File Rename Hang:**
  Fixed the file list never finishing loading after renaming a file on Linux.

- **List Sort Order:**
  The list view now preserves your chosen sort order after copy/move and folder navigation.

- **Narrow-Window Clipping:**
  Fixed clipped column titles in the Jobs dialog, truncation in the Job Manager dialog, and adjusted the main
  window minimum and default sizes.

- **Crypt OAuth Refresh:**
  Fixed a false "configuration changed" notice when OAuth tokens were refreshed for an encrypted config.

- **Legacy Rclone & Localization:**
  Fixed Send to Mobile on older rclone (&lt;1.66), Korean text corruption in custom dialogs, and a clipped Update
  button in the Embedded Rclone settings.
